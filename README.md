# Hello World in C

This is my first C programming project and my first entry in my engineering portfolio.

## 📌 About the Project

This program is a simple **Hello World** program written in C. It demonstrates the basic structure of a C program and prints a message to the console.

## 🛠️ Technologies Used

* **Programming Language:** C
* **Compiler:** GCC

## 💻 Source Code

```c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");

    return 0;
}
```

## ▶️ How to Run

### 1. Compile the program

```bash
gcc hello.c -o hello
```

### 2. Run the program

**Windows:**

```bash
hello.exe
```

**Linux/macOS:**

```bash
./hello
```

## 📤 Output

```text
Hello, World!
```

## 🎯 Concepts Learned

* Basic structure of a C program
* `#include` preprocessor directive
* `main()` function
* `printf()` function
* `return 0`
* Compiling and running a C program
